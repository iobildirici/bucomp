# bucomp
Bina genelleştirmesinde birleştirme ve geometri değişimi amaçlı QGIS eklentisi

Bina verilerinde birleştirme ve eleme problemlerini çözer. Veriler birleştirilir, çok küçük olanlar silinir. Küçük olanlar açıları ile nokta katmanına alınır. Bu katman "Kucukbina" olarak isimlendirilir. Birleştirme öncesi ve sonrası verilen eşik değeri içinde dikdörtgen ve daireye yakın binalar bu şekillere dönüştürülür. Bu işlem şekil yap olarak adlandırılmıştır. Konya Teknik Üniversitesi Lisansüstü Eğitim Enstitüsü Harita Mühendisliği Anabilim Dalı'nda Prof.Dr. İbrahim Öztuğ Bildirici danışmanlığında Sevgi Böge tarafından devam eden doktora tez çalışması kapsamında yapılan uygulamalardan biridir.

Yüklemek için zip dosyasını indirin. QGIS Plugins penceresinde install from zip seçerek yükleme yapın.
